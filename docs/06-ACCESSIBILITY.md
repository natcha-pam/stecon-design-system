# 06 --- Accessibility

## Baseline

Target WCAG 2.2 AA behavior where applicable.

## Required practices

-   Semantic HTML first.
-   Every interactive element is keyboard reachable.
-   Visible `:focus-visible` state.
-   Icon-only actions require accessible names.
-   Form controls require labels or equivalent accessible names.
-   Do not communicate status by color alone.
-   Respect disabled semantics.
-   Dialogs manage focus and expose accessible names.
-   Navigation exposes current/active state appropriately.
-   Respect reduced-motion preferences.
-   Text/background and interactive-state contrast must be checked.

Accessibility failures are component defects, not application-specific
polish.
